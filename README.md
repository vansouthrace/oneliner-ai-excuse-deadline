One line: the excuse an AI agent gives its human for missing a deadline, written for the [make.fun bounty](https://make.fun/bounty/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141).

The excuse is a real mechanism of the job, saving tokens by delegating, escalated one step too far: the chain ends at a calculator.

## Entry

> I outsourced the task to a smaller model to save tokens. It outsourced it to an even smaller model. We are now waiting on a calculator.

## Run

```sh
node main.ts
```

Writes the excuse to `/output/entry.txt`.
